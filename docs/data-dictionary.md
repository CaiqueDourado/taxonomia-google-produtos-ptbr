## Conventions

- Encoding UTF-8 without BOM, comma separated, header in the first line, `\n` line endings.
- Paths use ` > ` between levels, exactly like Google's files. Booleans are `True` / `False`.
- `google_id` is the key for both tables and for `arvore.json`.
